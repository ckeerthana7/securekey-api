# SecureKey API

A backend API project built using Python and FastAPI to explore secure authentication and API key management.

## Features

- User registration and login
- JWT-based authentication
- Protected API endpoints
- API key creation and management
- API key hashing
- API key revocation
- Automated testing using Pytest

## Technologies Used

- Python
- FastAPI
- SQLite
- SQLAlchemy
- JWT
- Pytest
- Swagger UI

## API Testing

Swagger UI is used to interact with the API and test its endpoints.
